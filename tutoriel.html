Tutoriel : Envoyer de l'argent vers un compte PIX

Étape 1 : Téléchargez l'application

Téléchargez gratuitement l'application TapTap Send sur votre smartphone.

Étape 2 : Créez votre compte

Inscrivez-vous et choisissez le Brésil comme pays de destination.

Étape 3 : Entrez le code promo

Utilisez le code BENOIT1123 lors de votre premier envoi avec TaptapSend et recevez €10,00 lorsque vous envoyez €25,00 ou plus.

Étape 4 : Renseignez la clé PIX

Saisissez le montant en euros. L'application vous demandera la Clé PIX (Chave PIX) de votre destinataire (CPF, téléphone ou email).

Étape 5 : Validez !

Payez avec votre carte bancaire française. L'argent sera transféré en quelques secondes sur le compte brésilien !
